# Donate

Minimal donation page for GitHub Pages.

- Boosty: https://boosty.to/free_vibrancy/donate
- Crypto: BNB Chain, Ethereum, Bitcoin, TRON, Arbitrum, Solana, Base, Polygon, TON, Cosmos
- Automatic language detection with EN / RU / BE / DE / PL switcher
- QR codes are generated in the browser

## GitHub Pages

Open **Settings → Pages** and set **Source** to **GitHub Actions**. The included workflow deploys the site on every push to `main`.

Expected URL: `https://abdulkus.github.io/donate/`
